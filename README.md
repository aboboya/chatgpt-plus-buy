## 一、为什么国内的卡付不了款

OpenAI 的收款结算统一由 Stripe 处理，目前只接受境外发行的 Visa / Mastercard / American Express 信用卡，且账单地址需与发卡地一致。

* **发卡地限制**：国内各大银行发行的普通储蓄卡、银联单标卡、以及绝大多数双币卡都会被支付网关直接拦截。这与你的账户余额、银行征信无关，属于纯粹的发行区域限制。
* **支付工具限制**：OpenAI 官方目前不支持支付宝、微信支付。
* **多次失败风险**：同一个账号如果短时间内连续绑卡失败，会直接触发 Stripe 的风控锁，轻则进入 24-48 小时冷却期，重则导致支付接口被永久拉黑。失败一两次后请勿连续重试。
